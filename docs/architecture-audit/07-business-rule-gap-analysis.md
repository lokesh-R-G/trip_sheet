# Business Rule Gap Analysis

This document evaluates the existing frontend implementation against the 10 authoritative business rule groups established in Section 3 of the Product Requirements.

---

## 2. Summary of Business Decisions Requiring User Confirmation

1. **Salary Formula & Bata Calculation**: The exact trip Bata calculation formula (flat per trip vs. per kilometer vs. per day) is not finalized.
2. **Statutory Deductions**: Current mock components include arbitrary numbers for "Driver Welfare Fund" (₹500); PF, ESI, and TDS deduction policies need legal parameters.
3. **Advance Recovery Cap Policy**: The code implements an arbitrary 30% warning threshold (`advanceRecs > gross * 0.3`). The company's legal/HR policy must define whether recovery is strictly capped or configurable.
4. **Fuel Deduction Tariff Valuation**: Currently uses `settings.defaultFuelPricePerLitre` (₹94.50). Confirmation is needed on whether fuel deduction should use the fixed benchmark price, the average bunkering price from recent top-ups, or the exact pump price on the trip route.
5. **TLCM Pro API Specification**: Endpoint URLs, auth tokens (OAuth2 vs. API Key), payload schemas, and webhook support for tyre lifecycle synchronization remain unverified against the TLCM Pro codebase.
